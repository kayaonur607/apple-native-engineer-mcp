# Free community pilot and evidence plan

Apple Native Engineer is completely free, MIT-licensed and open source. No paid plan, payment system, license key or sales funnel is planned. The filename is retained to preserve existing links.

Invite voluntary users through a GitHub Discussion or issue template. Do not collect proprietary source: ask for a public reproduction, tool version, OS, command, expected behaviour and actual finding codes. Never publish user results without consent.

A useful first pilot includes three to five volunteers and several distinct public apps. Record installation completion, first successful tool call, false positives verified against source, repeat use and documentation confusion. Track denominators and unknowns. No participation or outcome has been claimed yet.

The external Food Truck audit is a recorded source scan, not a user pilot or a measured accuracy benchmark. Classify findings manually before computing precision. Recall needs a separately labeled defect set; passing clean fixtures alone cannot establish it.

The animated video explains recorded MCP calls. The runtime sample provides actual simulator captures in light and dark. Keep both labeled with their evidence scope. Next voluntary feedback questions: Did installation work? Was at least one finding useful? Which finding was incorrect? What prevented a second use?

# Brand assets

The mark combines code brackets with a verification check. Dark navy, mint and white communicate local engineering
and inspectable evidence. The logo and README hero are editable SVG source, with accessible labels and no external
fonts, scripts or embedded tracking. They deliberately avoid Apple's logo and any implication of endorsement.

Use factual language: static findings, recorded tests, verified SDK declarations. Do not describe a static audit as
App Store approval, runtime accessibility certification or guaranteed release readiness. Keep test counts in the README
and generated evidence rather than baking them into decorative artwork.

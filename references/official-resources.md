# Official Apple Documentation & Primary Authority

This document indexes the primary, authoritative official Apple documentation and design resources that govern all guidance provided by the `apple-native-engineer` skill.

---

## 1. Primary Authority Hierarchy

Apple's published documentation, HIG specifications, and Developer API references serve as the single source of truth for platform behavior and design standards.

| Resource Name | Official URL | Authority Scope | Date Verified |
| :--- | :--- | :--- | :--- |
| **Apple Human Interface Guidelines (HIG)** | [developer.apple.com/design/human-interface-guidelines](https://developer.apple.com/design/human-interface-guidelines/) | Foundational principles, layout rules, component standards, materials, and input guidelines across iOS, iPadOS, macOS, visionOS, and watchOS. | November 2026 |
| **SwiftUI Documentation** | [developer.apple.com/documentation/swiftui](https://developer.apple.com/documentation/swiftui/) | Declarative UI framework, state management, views, modifiers, and platform bridges. | November 2026 |
| **UIKit Documentation** | [developer.apple.com/documentation/uikit](https://developer.apple.com/documentation/uikit/) | Core touch event handling, view controllers, gesture recognizers, and legacy interoperability. | November 2026 |
| **AppKit Documentation** | [developer.apple.com/documentation/appkit](https://developer.apple.com/documentation/appkit/) | Mac-specific windows, menus, toolbars, panels, and pointer handling. | November 2026 |
| **Apple Accessibility Guidelines & APIs** | [developer.apple.com/accessibility](https://developer.apple.com/accessibility/) | Accessibility traits, VoiceOver protocols, Dynamic Type metrics, and inclusive input standards. | November 2026 |
| **SF Symbols Specification** | [developer.apple.com/sf-symbols](https://developer.apple.com/sf-symbols/) | System iconography catalog, optical sizing, symbol effects (bounce, pulse, replace), and rendering modes. | November 2026 |
| **Apple Design Resources** | [developer.apple.com/design/resources](https://developer.apple.com/design/resources/) | Official Figma, Sketch, and XD UI kits, device templates, and typographic metrics. | November 2026 |
| **Swift Language & Concurrency Documentation** | [swift.org/documentation](https://www.swift.org/documentation/) | Language specifications, `@Observable` macro mechanics, Swift 6 strict concurrency, and actors. | November 2026 |
| **App Store Review Guidelines** | [developer.apple.com/app-store/review/guidelines](https://developer.apple.com/app-store/review/guidelines/) | Mandatory requirements governing safety, performance, design, legal, and privacy standards. | November 2026 |

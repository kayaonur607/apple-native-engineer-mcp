## Reporting a Vulnerability

We take the security and integrity of our open-source skills seriously. If you discover a security vulnerability, unintended prompt injection vector, or unsafe code generation pattern in `apple-native-engineer`, please follow these guidelines:

1. **Do not create a public GitHub issue.**
2. Send a detailed report via email to the maintainers or use GitHub's private security advisory reporting tool on the repository.
3. Include:
   - Description of the vulnerability or injection risk.
   - Steps to reproduce.
   - Affected agent platforms (e.g. Claude Code, Codex, Cursor).
   - Potential impact.

Maintainers will acknowledge receipt within 48 hours and provide a remediation timeline.

# GitHub skill installation

GitHub is the sole product distribution source. Clone the repository and use its installer:

```bash
git clone https://github.com/kayaonur607/apple-native-engineer-mcp.git
cd apple-native-engineer-mcp
./scripts/install-skill.sh
```

For executable MCP tools and automatic version updates, follow the [GitHub launcher guide](../docs/UPDATES.md). The MCP's skill resource updates with its selected release; separately copied skills do not update automatically. This page is retained at its previous URL so existing documentation links continue to resolve.
